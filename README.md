# pos-project

A modern Retail Point of Sale (POS) system built with Next.js, Tailwind CSS, NestJS, and TypeORM SQLite.

## Project Structure
- `retail-pos-fronten`: Next.js frontend with Tailwind CSS and responsive POS UI.
- `retail-pos-backend`: NestJS backend API with TypeORM SQLite database.

## Getting Started

### 1. Backend
```bash
cd retail-pos-backend
npm install
npm run start:dev
```
Backend runs on `http://localhost:3001/api`.

### 2. Frontend
```bash
cd retail-pos-fronten
npm install
npm run dev
```
Frontend runs on `http://localhost:3000`.
